# BUTTERFLY Architecture

## Pipeline

1. Layer/Edge Registry
2. Reference Trajectory Runner
3. Perturbation Injector
4. Parallel Perturbed Runner
5. Deviation Tracker
6. Boundary-Crossing Detector
7. Feedback Amplification Analyzer
8. Emergence Comparator
9. Systemic Consequence Scorer
10. Audit Reporter

## Inputs

- layered system state
- inter-layer couplings
- thresholds/boundaries
- source perturbation
- run horizon
- optional feedback edges

## Outputs

```json
{
  "initial_perturbation": 0.05,
  "propagation_depth": 4,
  "cross_layer_amplification": 6.2,
  "boundary_crossings": 2,
  "feedback_gain": 1.8,
  "emergence_score": 0.44,
  "systemic_consequence": 0.79
}
```

## Design principle

A system is not sensitive merely because one variable changes.

BUTTERFLY targets perturbations that:
- travel,
- amplify,
- cross boundaries,
- and alter the system-level regime.

## Integration

JELLYFISH models dependency cascades.

MANTIS detects nonlinear transition precursors.

RHINO applies severe shocks.

BUTTERFLY complements them by focusing on **small perturbation → large consequence** dynamics.
