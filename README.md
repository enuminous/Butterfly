# BUTTERFLY — EFMW Zoo #46

**Boundary-Under-Test Transition, Emergence and Recursive Feedback across Layered Yield**

BUTTERFLY is an experimental EFMW-inspired framework for measuring how small perturbations propagate through interconnected layers, cross operational boundaries, amplify through feedback, and produce disproportionately large emergent effects.

## Core question

> Which small changes remain local, and which ones trigger recursive propagation into a qualitatively different system state?

BUTTERFLY closes the second 23-animal Zoo cycle by testing sensitivity, amplification, boundary crossing, and emergent consequence across layers.

## Primary outputs

- perturbation sensitivity
- propagation depth
- cross-layer amplification
- boundary-crossing count
- recursive feedback gain
- emergence score
- local/global yield ratio
- systemic consequence score
